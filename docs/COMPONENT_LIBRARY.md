# Component Library

Version: 1.0

---

# Philosophy

Every visual element should exist only once.

Pages should be assembled from reusable components rather than bespoke layouts.

This keeps the design consistent and makes future maintenance straightforward.

---

# Core Components

## Site Header

Purpose

- Branding
- Primary navigation

Requirements

- Sticky after scrolling
- Mobile responsive
- Consistent across all pages

---

## Hero

Purpose

Create excitement.

Must include

- Festival name
- Date
- CTA
- Short tagline

Optional

- Countdown
- Hero artwork

---

## Countdown

Displays

- Days
- Hours
- Minutes

Future enhancement

Automatically changes to:

"Today's the day!"

when appropriate.

---

## Section Header

Consists of

- Eyebrow
- Heading
- Intro paragraph

Used throughout the site.

---

## Feature Card

Used for

## News Card

## Call To Action

Large promotional block.

Volunteer

Become a Sponsor

Plan Your Visit

---

## Footer

Contains

- Festival details
- Contact
- Copyright
- Social links (future)

---

# Design Rules

Every component should:

- work independently
- be responsive
- support dark/light backgrounds
- avoid fixed widths where possible
