# Drinks Layout v3

## Design decision

The Drinks page uses a single mixed list for:

- Beer
- Cider
- Wine
- Gin

Each category uses a restrained background tint and type badge rather than a separate major section.

This makes the page work better as an on-the-day festival menu and QR destination.

## Desktop row structure

Each row contains:

1. Product artwork
2. Drink type badge
3. Producer, name, description and flavour tags
4. Style and ABV
5. Favourite control

## Mobile

Rows collapse into a compact stacked layout but preserve:

- artwork
- name
- description
- tags
- style
- ABV
- favourite control

## Filters

Visitors can filter by:

- text search
- type
- style
- ABV

The same structure automatically includes wine and gin once entries are added to those collections.
