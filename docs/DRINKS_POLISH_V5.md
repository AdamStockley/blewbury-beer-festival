# Drinks Polish v5

## Changes

- Emoji tasting controls replaced by simple SVG outline icons.
- Like fills green when selected.
- Not-for-me fills burgundy when selected.
- All search, select and clear-filter controls now use a shared 48px height.
- My Festival Passport now includes a progress bar.
- A drinks-line-up disclaimer has been restored beneath the list.
- Existing local three-state tasting behaviour remains unchanged.

## Disclaimer

The public page now clearly states that the planned drinks line-up may change before or during the festival if products become unavailable.
